ABOUT CHARAN MEDIA

Modular Media Tools

Charan Media is a full-stack media downloader built with HTML, CSS, JavaScript, Python FastAPI, FFmpeg and yt-dlp. Each platform has its own modular handler — validator, detector, processor and formatter — managed by a central Platform Manager. New platforms can be added without touching existing code.
